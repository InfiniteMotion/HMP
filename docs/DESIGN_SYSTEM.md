# HMP Design System

> 团队内部设计规范 · v5.10 · 2026-05-21
>
> 适用平台：Android (Jetpack Compose) · iOS (SwiftUI) · Desktop (Compose Desktop)
>
> 设计令牌（颜色/字体/动效）三平台共享，实现遵循各平台原生 API。

---

## 1. 设计原则

HMP 是一个纯本地、跨平台的音乐播放器。不做云同步、不设账号、不追踪。

**三条核心原则：**

- **纯粹**。UI 是音乐的容器，不应喧宾夺主。克制装饰，让内容和封面说话。
- **私密**。暗色模式下主色从激进的红切换为柔和的浅蓝——夜间听歌不应被刺眼的红色打断。
- **用心但安静**。毛玻璃是 HMP 的视觉签名，但它是空间层次的表达，不是炫技。细节做足但不张扬。

**明暗双主题同等对待。** 亮色不是默认，暗色不是附属——两套色板各自设计，不允许简单的颜色翻转。

## 2. 颜色系统

### 2.1 品牌色

HMP 的品牌标识是**红蓝冷暖对比**。红色代表音乐的情感温度，蓝色代表技术的理性克制。

| 令牌 | 色值 | 色样 |
|------|------|------|
| `HDRed` | `#C92C2C` | ████ |
| `HDBlue` | `#002FA7` | ████ |

### 2.2 亮色主题

| 令牌 | 色值 | 用途 |
|------|------|------|
| `primary` | `#C92C2C` | 按钮、选中态、链接 |
| `primaryContainer` | `#1976D2` | 主色的容器背景（蓝色，与红形成冷暖对比） |
| `secondary` | `#002FA7` | 标签、辅助强调 |
| `background` | `#FFFFFF` | 页面底色 |
| `surface` | `#FFFFFF` | 卡片表面 |
| `surfaceVariant` | `#E1E2EC` | 次级表面（iOS cardBackground 为 `#F5F5F7`） |
| `onSurface` | ≈ `#1E1E1E` | 主要文字 |
| `onSurfaceVariant` | ≈ `#616161` | 次要文字 |
| `divider` | ≈ `#E0E0E0` | 分割线 |

### 2.3 暗色主题

> **关键设计决策：** 暗色模式的主色从 `#C92C2C`（品牌红）切换为 `#90CAF9`（柔和浅蓝）。红色退居到 `primaryContainer`（`#CF6679` 粉红）。这是为了夜间听歌的沉浸感——大面积红色在暗背景下过于刺眼。

| 令牌 | 色值 | 用途 |
|------|------|------|
| `primary` | `#90CAF9` | 按钮、选中态、链接 |
| `primaryContainer` | `#CF6679` | 主色的容器背景 |
| `secondary` | `#F48FB1` | 标签、辅助强调 |
| `background` | `#121212` | 页面底色 |
| `surface` | `#121212` | 卡片表面 |
| `surfaceVariant` | `#44464F` | 次级表面（iOS cardBackground 为 `#242426`） |
| `onSurface` | ≈ `#F2F2F2` | 主要文字 |
| `onSurfaceVariant` | ≈ `#ADADAD` | 次要文字 |
| `divider` | ≈ `#333333` | 分割线 |

### 2.4 主题切换

三种模式：跟随系统 (`system`) · 强制亮色 (`light`) · 强制暗色 (`dark`)。用户选择持久化到本地存储。

### 2.5 动态主题（专辑取色）

播放音乐时，从当前专辑封面提取主色、背景色和强调色，实时生成动态色板。提取规则：

1. 主色 = 封面上最鲜艳的颜色，并确保与背景对比度 ≥ 3.0:1（WCAG AA）
2. 背景色 = 封面上最暗/最不饱和的颜色
3. 强调色 = 色相上距离主色最远的检测颜色

**何时使用：** 播放器页面、迷你播放器背景、动态氛围背景。预设主题和动态主题共存——用户可以切换回预设。

## 3. 字体系统

### 3.1 平台字体

| 平台 | 正文字体 | 说明 |
|------|----------|------|
| Android | **HarmonyOS Sans** | 6 字重 (Thin→Black)，内置在 APK |
| iOS | **SF Pro** | 系统字体，HarmonyOS Sans 在 iOS 不可用 |
| Desktop | 系统默认 | 跟随操作系统 |

### 3.2 排版层级

15 级 Material3 字体缩放表，三平台统一。以下是关键使用场景（完整表见代码 `TypographyTokens`）：

| 层级 | 使用场景 |
|------|----------|
| `displayLarge` (40) | 播放器歌曲标题 |
| `displayMedium` (24) | 页面大标题 |
| `headlineMedium` (18) | 区块标题 |
| `titleMedium` (16) | 卡片标题、迷你播放器歌名 |
| `titleSmall` (14) | 列表项标题、导航标签 |
| `bodyLarge` (16) | 正文 |
| `bodyMedium` (14) | 辅助说明 |
| `bodySmall` (12) | 次要信息、时间戳 |
| `labelLarge/Medium/Small` | 标签、按钮文字、徽标 |

**字重规则：** 标题用 Bold，标签用 Medium，正文用 Regular。

## 4. 毛玻璃效果

毛玻璃是 HMP 最核心的视觉特征。它不只是一种装饰——它表达空间层次：**玻璃卡片漂浮在动态背景之上**。

### 4.1 使用原则

| 原则 | 说明 |
|------|------|
| **底部区域必用** | 底部导航栏、迷你播放器——它们是悬浮层，必须有毛玻璃 |
| **对话框必用** | 所有弹窗和对话框 |
| **不滥用** | 内容区卡片（如列表、网格）**不**使用毛玻璃，保持清晰可读 |
| **配合动态背景** | 毛玻璃的价值在于透过它看到下方动态内容（专辑封面极光等），纯色背景上玻璃效果无意义 |

### 4.2 三平台实现

| 平台 | 实现方式 | 默认参数 |
|------|----------|----------|
| Android | [Haze 库](https://github.com/chrisbanes/haze) | blur=20dp, noise=0.15, tint=surface×22% |
| iOS | 原生 `.ultraThinMaterial` | 系统控制 |
| Desktop | Haze 库（同 Android） | 同 Android |

### 4.3 强度分级

| 级别 | 强度 | 适用 |
|------|------|------|
| Ultra Thin | 0.08 | 极微妙，几乎透明 |
| Thin | 0.25 | 轻度 |
| Regular | 0.50 | 默认 |
| Thick | 0.75 | 需要更不透明时 |
| Ultra Thick | 1.00 | 几乎不透明，极少使用 |

用户可在设置中调节毛玻璃强度（`hazeIntensity` 0–1）、模糊半径、噪点强度。这些设置跨平台同步（shared 模块中的 `SettingsRepository`）。

## 5. 动效

### 5.1 持续时间

| 类型 | 时长 | 适用 |
|------|------|------|
| 微交互 | 200ms | 按钮点击、开关、选中切换 |
| 过渡 | 400ms | 页面导航、组件出现/消失 |
| 复杂编排 | 650ms | 多元素协同动画 |
| 氛围背景 | 3000ms | 极光旋转、光斑漂移 |

### 5.2 缓动

| 曲线 | 用途 |
|------|------|
| Ease In Out `(0.4, 0, 0.2, 1)` | 默认，通用过渡 |
| Ease Out `(0.2, 0, 0.1, 1)` | 元素进入/出现 |
| Ease In `(0.6, 0, 0.8, 1)` | 元素退出/消失 |

### 5.3 弹簧

| 类型 | 用途 |
|------|------|
| Medium | 胶囊展开/折叠、导航切换（弹而不跳） |
| Bouncy | 封面弹出、列表项滑出（活泼） |
| Gentle | 滚动、拖拽回弹（柔和不抢戏） |

### 5.4 导航过渡

页面间切换统一使用：缩放 (0.95→1) + 淡入，持续 400ms，Ease In Out。退出动画反向。

### 5.5 封面旋转

播放中专辑封面持续旋转，每圈 8000ms，线性匀速。暂停时立即停止（不减速）。

## 6. 三平台布局

### 6.1 Android & iOS（移动端）

移动端布局一致：4 个底部 Tab（首页/封面/列表/我的） + 迷你播放器悬浮条。

- **底部导航：** 两颗药丸形毛玻璃胶囊并排——左侧导航（4 Tab），右侧播放控制
- **导航行为：** 默认展开导航、折叠播放；播放开始后自动切换为展开播放、折叠导航；5 秒无操作恢复默认
- **迷你播放器：** 悬浮在内容区上方，点击进入全屏播放器

### 6.2 Desktop（桌面端）

桌面端的核心差异：**窗口可自由缩放，布局需要响应式适配**。

**断点：**

| 宽度 | 分类 | 布局策略 |
|------|------|----------|
| < 600dp | Compact | 同移动端——底部胶囊 + 迷你播放器 |
| 600–840dp | Medium | 底部胶囊 + 迷你播放器，内容区多列 |
| ≥ 840dp | Expanded | **侧边 NavigationRail** 替代底部 Tab，全宽内容 |

**桌面端独有特性：**

- **自定义标题栏**（40dp，无边框窗口），播放时沉浸式透明
- **NavigationRail**（80dp 宽侧边栏）在 Expanded 模式替代底部导航
- **系统托盘**：托盘图标 + 播放控制（播放/暂停/上一首/下一首）
- **键盘快捷键**：Space 播放/暂停，方向键切歌/调音量，Esc 返回，Ctrl+F 搜索
- **响应式内容区**：封面网格列数、列表信息密度、播放器布局（宽屏左右分栏，窄屏上下堆叠）均随窗口宽度自适应
- **文件选择器**：原生桌面文件对话框，用于添加音乐库目录

**桌面端使用 Compose Desktop，设计令牌（颜色/字体/动效/毛玻璃）与 Android 共享同一套代码。**

## 7. 动态背景

播放时，HMP 从专辑封面取色生成动态氛围背景。三种风格：

| 风格 | 效果 | 性能 |
|------|------|------|
| **流体极光**（默认） | 双层封面旋转 + 大半径模糊 + 饱和度增强 | 中等 |
| **沉浸光斑** | 3–7 个调色板光斑在轨道上漂移呼吸 | 较低 |
| **复古模糊** | 单封面放大模糊，最简洁 | 最低 |

所有风格之上叠加垂直渐变遮罩——暗色 `Black(0.3)→透明→透明→Black(0.6)`，亮色 `White(0.1)` 通体——确保前景文字始终可读。用户可在设置中切换风格。

## 8. 组件设计模式

以下不是逐个组件的像素规范（细节在代码中），而是**跨平台的设计规则**。

### 8.1 毛玻璃卡片

- **形状：** 大圆角药丸形（底部栏、迷你播放器）或圆角矩形（对话框）
- **边框：** 极细半透明描边（`onBackground` 14% alpha），替代阴影来表达边界
- **不要阴影 + 毛玻璃同时用。** 玻璃本身就是空间层次，再加阴影 = 过设计

### 8.2 按钮

- 填充按钮用 `primary` 色背景 + 白色文字
- 轮廓按钮用 `primary` 色边框 + 透明背景
- 文字按钮不加背景，只变颜色
- 所有按钮 hover/press 有 200ms 微交互反馈

### 8.3 列表项

- 封面 + 标题（Bold）+ 副标题（Regular）+ 右侧辅助信息
- 选中态用 `primary` 色高亮
- 编辑模式出现复选框和多选工具栏

### 8.4 对话框

- 统一使用毛玻璃背景
- 居中显示，点击外部或按 Esc（桌面端）关闭
- 内容过长时内部可滚动

## 9. 平台差异速查

| | Android | iOS | Desktop |
